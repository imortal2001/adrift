## Art

Terrain, water, sky, flora, the reef, raft and debris are generated
procedurally at load time. The wildlife models in `assets/models/` are **not** —
see the table below, and read the warning attached to it.

`assets/models/reef_fish.glb` is the exception among the files in that folder:
it is generated from scratch by `tools/build_fish.py`, so it is original work
and carries no third-party licence. It is not in the table for that reason.

Wildlife you model yourself in Blender is original work and needs no entry.

If you ship a *third-party* model in `assets/models/`, record it below —
one row per file, with the licence and a link to the original. CC BY requires
this; CC0 does not, but list it anyway so the provenance is never in doubt.
Models used only as on-screen reference while modelling are not distributed
and do not belong in this table.

> ⚠️ **The five `sharksly` models above carry a licence the uploader may not
> have been able to grant.** Each Sketchfab listing is tagged CC Attribution and
> links a Steam Workshop pack as its source. That pack's own description states
> it was built *"using the models from Jurassic world evolution 2 as a base"*
> and credits Frontier Developments PLC, Universal, Amblin, ILM and Stan Winston
> Studios. The rigs corroborate it: they are production game rigs, complete with
> `def_hindJiggle_joint` secondary-motion bones, which is not something a fan
> model carries.
>
> A CC BY tag applied to assets derived from Frontier's commercial meshes does
> not make them CC BY. Treat these as **unlicensed for redistribution** until
> someone establishes otherwise. They are in the tree as a prototype decision,
> recorded here rather than left implicit. Before this repository is published,
> shipped, or made commercial they should be removed or replaced.
>
> **Replacement exists.** `tools/build_sauropod.py` regenerates an original,
> licence-clean sauropod (`blender/sauropod_procedural.blend`) from the starter
> blockout, animated with the same clip set. The other four species have
> starters in `blender/` waiting for the same treatment.

The animation clips on all five (`Idle`, `Walk`, `Run`, `Attack`, `Death`) are
original work, generated by `tools/glb_anim.py`. Every one of these models
shipped with no animation at all. Those clips are not encumbered by the above;
the meshes, skins, textures and skeletons they drive are.

All five have had their embedded textures shrunk by `tools/glb_textures.py`:
base colour re-encoded to JPEG at 2048, normal maps resized to 1024. The raptor
and stegosaur shipped 4096x4096 normal maps costing ~16 MB each, which was most
of their file size. That took the set from 76 MB to 23 MB.

`tools/glb_reweight.py` is not currently applied to anything. It was written for
the previous raptor, whose finger chain zigzagged badly enough to swing its claws
into spikes; the model now in place does not have that fault. The tool is kept
because the problem is common in converted rigs.

> ⚠️ **`raptor.glb` needs its provenance filled in.** It was supplied as a
> download (`~/Downloads/velociraptor/`) whose folder carried no licence file —
> only `source/` and `textures/`. That layout is what a Sketchfab download
> looks like, and a Sketchfab zip normally ships a `license.txt` at its root,
> so the licence has most likely been separated from the files rather than
> never existed. Track down the original listing and record the author and
> licence here before this repository is shared or made public. If it turns out
> to be **ND** (no derivatives) it cannot stay: the file has already been
> converted, which is a derivative.
